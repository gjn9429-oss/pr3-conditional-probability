# Практична робота № 5–6

Тема: «Умовна ймовірність, теореми додавання та множення ймовірностей у діагностиці та аналізі програмних систем».

Студент: Римаренко Євгеній Олександрович.

Група: ІВ-25-1.

Університет: Державний університет «Житомирська політехніка».

Варіант: 1.

## Залежності

Python 3.10 або новіший, matplotlib.

```powershell
python -m pip install matplotlib
```

## Запуск

Виконувати з основної папки проєкту:

```powershell
python main.py
python block2.py
python block3.py
python block4.py
```

Кожна команда запускає окремий блок. Результати виводяться в термінал.

## Зміст

- `main.py` — блок 1: умовні ймовірності запитів до БД, від 100 до 1 000 000 випробувань.
- `block2.py` — блок 2: відмови двох маршрутизаторів, 100 000 днів.
- `block3.py` — блок 3: надійність вебсистеми з резервуванням, від 100 до 1 000 000 випробувань.
- `block4.py` — блок 4: ланцюжок трьох мікросервісів, 100 000 запитів.

Блоки 1, 3 і 4 зберігають графіки в папці `graphics` без відкриття окремого вікна.
У `results` наведено збережені результати запуску, у `report` — звіт у PDF.
Фіксоване зерно генератора `SEED = 20261014` забезпечує відтворюваність результатів.
