## Запуск у VS Code

Потрібні Python 3.10 або новіший та бібліотека Matplotlib. Відкрити папку проєкту або `PR5_6.code-workspace` у VS Code. У терміналі PowerShell виконати:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Активація середовища не потрібна. Командою **Python: Select Interpreter** вибрати `.venv\Scripts\python.exe`. Для запуску з відлагоджувачем натиснути F5 і вибрати «Практична 5–6 — усі блоки».

Незалежна перевірка готових результатів:

```powershell
.\.venv\Scripts\python.exe verify_results.py
```

| 4, варіант 1 | Три послідовні мікросервіси; доступність і причини відмов | 100 000 запитів | 7 |

У блоках 1 і 3 використано контрольні точки одного накопичувального експерименту: рядок N містить його перші N випробувань. Для кожного блоку створено окремий генератор `random.Random(SEED + номер_блоку)`, базове зерно — **20261014**. Це забезпечує повторюваність результатів. Випробування моделюються як незалежні в часі; у блоці 1 події A та B всередині одного випробування залежні.

У блоці 4 причина відмови запиту — **перший недоступний сервіс**. Причини S1, S2 і S3 взаємовиключні, тому їхні частки можна додати. Додатково збережено кількість недоступностей кожного компонента; ці події можуть перетинатися, тому їхню суму не слід називати кількістю невдалих запитів.

## Файли результатів

Усі файли створюються в `results/` біля `main.py`, незалежно від поточної папки термінала.

- `block1.csv` — лічильники, п'ять потрібних частот і похибка P(B|A).
- `block2.csv` — сім точних і статистичних ймовірностей та абсолютні похибки.
- `block3.csv` — надійність вебсистеми для п'яти N.
- `block4.csv`, `block4_summary.csv` — причини відмов і загальна доступність ланцюжка.
- `block1_convergence.png`, `block3_convergence.png` — оцінки та абсолютні похибки.
- `block4_failures.png` — порівняння причин відмов із теорією.
- `results.json` — повні результати, параметри й дані середовища.
- `console.txt` — фактичний текст виводу програми.
