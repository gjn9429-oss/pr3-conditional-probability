## Опис проєкту

Моделювання випадкових подій і надійності програмних систем мовою Python:

- Блок 1: умовні ймовірності для запитів до бази даних.
- Блок 2: відмови двох незалежних маршрутизаторів.
- Блок 3: надійність вебсистеми з резервуванням серверів і баз даних.
- Блок 4: доступність ланцюжка трьох мікросервісів і причини відмов.

## Запуск

Потрібні Python 3.10 або новіший та бібліотека matplotlib.

```bash
python -m pip install matplotlib
python src/main.py
```

Команду запускати з головної папки проєкту, зокрема в терміналі VS Code.
Усі чотири блоки виконуються послідовно, результати виводяться в термінал.
Окремий блок можна запустити командою `python src/block1.py`
(так само для `block2.py`, `block3.py` та `block4.py`).
Графіки зберігаються в `graphics/`.

У блоках 1 і 3 використано від 100 до 1 000 000 випробувань,
у блоках 2 і 4 — по 100 000 випробувань.

## Файли

- `src/main.py` — запуск усіх блоків.
- `src/block1.py` — умовні ймовірності запитів до БД.
- `src/block2.py` — відмови маршрутизаторів.
- `src/block3.py` — надійність вебсистеми з резервуванням.
- `src/block4.py` — доступність мікросервісів і причини відмов.
- `graphics/` — графіки експериментів.
- `report/` — звіт у PDF.
